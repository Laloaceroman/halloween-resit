# Halloween en Resit

Landing del evento interno de Halloween de Resit: itinerario, música de terror y audio de Plancton.

Es un solo archivo (`index.html`) con todo incluido (imágenes, tipografía y audio), sin dependencias.

## Publicar con GitHub Pages

1. En el repositorio: **Settings → Pages**.
2. En **Source** elige **Deploy from a branch**.
3. Branch: **main**, carpeta: **/ (root)** → **Save**.
4. En uno o dos minutos queda en `https://laloaceroman.github.io/halloween-resit/`.
